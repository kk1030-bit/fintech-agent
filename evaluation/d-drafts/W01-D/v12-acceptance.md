二、四類客觀檢查（W01 要求先訂的）

【季度資料（對應 N01）】[手冊 F01]
1. 來源已經是單季的資料，不能再做一次相減。
2. 累計轉單季：Q2 單季 = Q2 累計 - Q1 累計；Q3 = Q3 累計 - Q2 累計；Q4 = 全年 - Q3 累計。只能在同公司、同年度、同口徑、前期值齊全時算。
3. 缺 Q1 或缺 Q3 時，不能硬算，要標缺值與原因。
4. 資產負債表是時點存量，四季不能相加。
5. TTM 流量需要四個連續季度。
6. 同一公告出現重複版本、只有財報期而沒有公告時間、合併與個體報表混用、單位換算、股數變動、季度排序、cutoff 之後的資料排除，都要有測試。
7. 公告時間無法驗證時，以 captured_at 當可得時間，不倒填成更早的日期。
8. 既有年度 DCF 的相容測試要保留。

【同業比較（對應 N02）】[手冊 F02]
下面的算例是手冊提供的合成驗算資料（synthetic_fixture），不是真實公司財報。
1. 股價 120、TTM EPS 6，P/E 應等於 20。
2. BVPS 30，P/B 應等於 4。
3. 營收 120 相對去年同季 100，YoY 應等於 20%。
4. 營業現金流 100、正值 CapEx 30，FCF 應等於 70。
5. EPS 小於等於 0 時 P/E 標「不適用」，分母小於等於 0 時 P/B 也標「不適用」，不能造出負值評級。
6. 同一個報價基準日沒有價格時標 NA，不能拿別家不同日期的價格補。
7. 最多比較 4 家公司；2330 要標「產業參照」，不能算進 2454 的同業平均。
8. 缺 DCF 參數就標 NA，不能用 0 代替。

【資料品質風險（對應 N03）】[手冊 F03]
1. 風險分高、中、低三級：關鍵資料缺失、未解決的矛盾、無法證明可得時間算「高」；資料標示過期或只有次要欄位缺失算「中」；所有既定檢查都通過算「低」。
2. 「低」只代表資料品質，不代表股價風險低。
3. 估值差距 = (DCF 每股值 - 同日市價) / 同日市價。差距大於等於 +15% 顯示「低於模型估值」；小於等於 -15% 顯示「高於模型估值」；其餘顯示「接近模型估值」。
4. 15% 只是專題的顯示門檻，不是經過驗證的投資規則；缺關鍵參數時顯示「無法判定」。
5. 收藏、排序、開舊報告、純讀，都不能自動啟動新的分析 job。

【關聯圖（對應 N06，條件式）】[手冊 F06]
1. 節點最多 20 個、關係最多 30 條。
2. 每一條關係都要有明示的來源，沒有來源就不畫線。
3. 供應或客戶關係不能用營收相關性或同分類去推。
4. 瀏覽、拖曳、搜尋不呼叫 LLM。
5. 有手機列表備援、點節點或線可看來源與日期。
