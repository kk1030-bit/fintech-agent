## 2. 每個新增畫面必畫的狀態

| 狀態 | 用在 | 畫法 |
|---|---|---|
| 載入中 | 全部 | 骨架／文字＋不重複送出 |
| 空白 | N2、N3、N5、N8 | 說明下一步，不放假資料 |
| 錯誤 | 全部 | 顯示可讀原因；HTTP 錯誤碼保留 |
| 未授權 | N1 | 「研究入口未啟用／需授權」，不顯示 token 欄位 |
| 排隊 queued | N2 | 顯示前面還有 job（一次只跑 1 個） |
| 暫停配額 paused_quota | N2、N8 | 顯示原因與累計預算，不歸零 |
| 資料不足 insufficient_evidence | N2、N5、N8 | 列出具體缺口，不顯示買賣評級 |
| 逾時 timed_out／失敗 failed／取消 cancelled | N2 | 顯示 stop_reason 與停在哪個 stage |
| NA | N7、N9 | 「NA＋原因」，永遠不顯示 0 |
| 過期 | N5、N6、N8 | 顯示資料時間與「快照過期」標籤 |
| 無來源 | N5、N6 | 「無來源」標籤，主張不可當事實 |
| FIXTURE／MOCK | 全部（W02–W04） | 頁首橫幅＋每列標籤 |
