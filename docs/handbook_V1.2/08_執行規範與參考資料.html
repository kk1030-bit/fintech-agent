風險與既定處置

  • 配額不足：W01用900次含整合/前瞻/展示的總預算與J估算日數；mock優先、正式分批，J=0暫停live，不多開key規避額度，不自動付費。
  • 模型下架或行為改變：模型ID与prompt版本化；只切換經組長核准且通過10個開發案的相容模型，正式實驗分版本，不混表。
  • 2GB仍不足：受控資料批次、單worker、PDF串行與DB配額監控；先量RSS再改並行，不能只買網域。未核准不增加月費。
  • 來源缺少/被封鎖：回傳no_data、保留旧快照與時間，結果標不足；禁止突破登入牆或猜財報數字。
  • 進度滑落：受阻24小時內找組長；W08核心凍結、W12所有功能凍結，後續只修critical問題。先刪除未列入必交的裝飾，不刪Agent閉環、線上PDF或評估。
  • C/E沒有素材：先做固定章節框架/版型，記受阻並由指定B/D/A交付，不把技術責任轉回C/E。
  • 技術人員缺席：組長備援B資料適配與D覆核runner，A備援展示；C/E保留最新交接附件，但不臨時負責修復。
  • 數據重分發風險：引用公開原始來源與短片段，保留授權註记；不把未授權全文或私人資料上傳外部AI，不宣稱目前能商業化售賣行情。

指定參考資料（C不用自行擴充書單）

以下公開入口於2026/09/13核對。C製作固定8筆文獻/文件卡：作者或機構、年份/查閱日、類型、研究問題、方法摘要、本專題採用點、不能據此聲稱的結論、原始URL。前三項只根據已閱讀全文/章節摘要，不捏造效能數字。

R01 ReAct: Synergizing Reasoning and Acting in Language Models，Yao等，2022初稿/2023版本。作為以行動取得觀察再調整研究的參考，不引用其一般任務分數作為股價預測能力。

R02 Toolformer: Language Models Can Teach Themselves to Use Tools，Schick等，2023。比較模型使用工具的設計思想；本專題沒有做其訓練程序，不宣稱重現Toolformer。

R03 FinRobot: An Open-Source AI Agent Platform for Financial Applications using Large Language Models，Yang等，2024白皮書。金融Agent平台的相關工作，作研究定位參考，不以其架構證明我們可獲利。

R04 Building effective agents，Anthropic，2024工程文章。用於workflow/agent區分、工具與停止条件，是工程觀點，不當作嚴格統一學術定義。

R05 Gemini function calling，Google官方文件。供實作函式schema、模型選工具與回傳工具結果；實際SDK版本由組長鎖定。

R06 Gemini API rate limits，Google官方文件。用於配額治理的背景，帳戶實際數字另由W01保存脫敏紀錄。

R07 Gemini API pricing，Google官方文件。區分免費與付費使用條件，不預測未來價格。

R08 fintech-agent固定版本程式，包含PROJECT_STATUS.md、web_app.py、main.py、requirements.txt、report_builder.py及macro_agent。是本專題實作基線，不是外部學術證據；狀態文件日期較舊，現況以程式及當週實測確認。
