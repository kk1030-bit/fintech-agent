既有架構與新增層

保留 Python/Flask 網站與既有資料/估值/報告模組，新增 Python LangGraph StateGraph 與 Gemini 官方 SDK。LangGraph 負責状态、條件分支與恢復；模型根據工具回傳決定下一步，才是本專題要驗證的 Agent 行為。

現有 /api/analyze 同步抓取資料並產圖。本期新增非同步研究入口；公開唯讀改讀已核准快取，不能因重新整理或切股票再執行研究。既有同步入口須納入相同授權/配額政策，不可留下繞過新佇列的耗資源路徑。保留相容性由組長和 A 確認，不默默刪除既有功能。

明確新增，不宣稱已存在

新增 research_jobs、job_events、evidence_versions、report_versions 等儲存契約與遷移，實際表名前綴由組長一次鎖定。現有 macro_data、fundamental_data 保留，不破壞正式資料。新增後端授權、人工核准、報告歷史和 Storage PDF 保存；目前程式沒有完整同版本發佈機制。

Web 接受任務後立即回 job_id；持續 Python worker 由啟動監督程式與 gunicorn 在同一個預定2GB instance 管理。不是 Flask request 返回後隨意開 thread。Web/worker 之一異常退出時終止服務交平台重啟。一次只允許一個活躍 job；DB 租約60秒、心跳20秒、輪詢2秒，並以 fencing/狀態版本避免舊 worker 覆寫新結果。研究和產 PDF 共用重工作限制，不另購付費 worker。

同一 idempotency_key 重送回既有 job；可重用結果鍵包含 ticker、question_version、snapshot_id、model_id、prompt_version。金鑰只在後端 env，資料表/RLS/Storage 權限需測試。LangGraph 記憶體狀態不是持久化完成，檢查點和預算都須保存到 Supabase。重啟保留累計請求，不聲稱外部 API 計費 exactly-once。

六工具契約

以下是新增適配層，實作先重用既有模組，不要求現在已有同名函式。所有工具只接受 schema 欄位，不接受 SQL、shell、任意 URL 或路徑。

  1. search_evidence(ticker, query, cutoff, limit)：查詢已入庫公開財報/公告/總經來源索引，limit 1至5，回來源ID、標題、發布與可得時間、摘要。新增索引不是已有新聞爬蟲。
  2. read_evidence(evidence_version_id)：取該 job 快照內不可變片段，最多1,200中文字，附段落、hash、精確原始來源連結。找不到就 no_data，不改抓任意網站。
  3. get_financial_snapshot(ticker, cutoff)：適配 report_downloader.py 的 FinMind 資料，回營收、淨利、TTM EPS、FCF、股數、淨負債等可用值。各值帶期間、合併口徑、幣別、單位、來源與可得時間；缺值為 null，不自行补齊預測。
  4. get_macro_snapshot(cutoff, series_ids)：讀 macro_data/FRED/台股市場的核准快照；series 白名單由 W02 鎖定為 CPI、政策利率、台股市場指標。區分資料觀察期與發布/修訂時間；拿不到歷史 vintage 就不能稱當時已知。
  5. get_price_window(ticker, end_at, sessions)：沿用 FinMind 行情適配，sessions 1、5、20，台股交易日；研究只讀 cutoff 前可得資料。明示原始/調整口徑，停牌或缺價為 no_data。
  6. calculate_metrics(operation, values, evidence_refs)：只接受 growth_rate、simple_return、pe_ttm、dcf_scenario、peer_comparison。peer_comparison仍在calculate_metrics內，不新增第七工具；季度/TTM、比較角色和指標遵循第03章。PE=同幣別同每股口徑股價/正TTM EPS；EPS<=0或資料不足回null+原因。DCF重用 valuation_agent/dcf_model.py，輸入至少包含 FCF 期間及單位、WACC、g、淨負債、股數；WACC>g、股數>0、單位相容才算。假設及敏感度單獨標示，不把內在價值當成交價。

Researcher 可選全部六工具。Reviewer 只能 read_evidence、get_financial_snapshot、get_macro_snapshot、calculate_metrics；需要新搜尋或股價視窗時，以具體 claim_id/required_evidence 退給 Researcher，不能隱性越權。

既有金融邏輯必查項

main.py 的部分缺值替代可能把營收/淨利比當PE、營收/營業利益比當PB；股價資料缺少時也有非股價序列替代。這些不能直接當真實市價比率。W03 B/D 需加明確測試與缺值狀態：PE/PB要有正確定義及來源，沒有就顯示不可用，不用看似合理數字補洞。

DCF已存在，但預設 WACC=9%、g=3%、FCF延伸、淨負債缺值與股數單位不代表適用每家公司。B用可手算的fixtures查核；D覆核結果。缺失資料不能只靠LLM猜。與本期主題無關的金融模型擴充不做。

記錄與停止

每個動作保存 job_id、event_seq、時間、角色、工具名、脫敏參數、輸入/輸出hash、引用ID、結果摘要、延遲、模型版本、prompt hash、usageMetadata。decision_summary僅簡短可驗證理由，不要求或顯示隱藏思考鏈。模型沒有資料庫、發佈或交易權限；上層驗證後保存。

預算 V1：以下數值是本專題設計上限，不是 Google 免費方案承諾

  • 同時執行 1 job；每 job 最多 8 次模型 HTTP 發送，Researcher、Reviewer、格式重試、網路重試全部共用；禁止 SDK 隱藏自動重試。
  • 每 job 最多 10 次工具調用、同一工具相同參數最多 2 次、補查最多 2 輪。工具不必每種都用，工具數不等於模型請求數。
  • 每 job 主動執行時間最多 180 秒，不含排隊和 paused_quota 等待；超時保存檢查點並標 timed_out，不冒充成功。
  • 每次模型輸入壓到 3,000 token 以內，文字輸出上限 1,500；啟用 thinking 時必須有可配置上限並納入預留。全 job token 准入預算 40,000，先保留再發送，按供應商 total usage 對帳；無法可靠預估的模型不得使用。不能只靠字數當精確 token。
  • 前 4 次請求可供初次研究，第 5 次優先保留覆核；第 6 至 8 次只供必要修正或覆核。不是強制固定五步：Researcher 可提早提出草稿；若覆核需工具回傳而剩餘不足，就停止，不能跳過覆核發佈。
  • 每日研究上限 J = min(6, floor(max(0, floor(0.8 * 實際RPD) - 同日其他用途保留次數) / 8))。W01 依真實帳戶設定，不能假設 J 一定大於 0；J=0 時只開快取展示與 mock 測試，組長處理額度問題，不切換付費。
  • RPM、TPM 用全專案排程器共同控制，預留 20% 餘裕；子模組摘要或其他用途若使用 Gemini，也要納入同一本帳。request_count 在送出前遞增，逾時或 429 不退回次數；token未知需保留估算，避免少算。
  • 短期限流遵守 Retry-After，再加抖動，最多 1 次重試且共用 8 次上限；日額耗盡或原因不明保存 paused_quota，不狂重試。恢复同一 job 的累計預算不歸零。

Gemini 的實際 RPM/TPM/RPD 隨模型及專案而異，按專案而非 API key 計算；應查看 AI Studio，不以學生訂閱推定 API 容量。官方限額。Google AI Pro 可能附帶需確認資格與啟用情況的開發者福利，未核對之前不計入可用額度。開發者方案。免費服務的資料使用政策依官方定價與條款確認，只使用公開研究素材，不上傳私人財務資訊。API 定價。

網站與持久線上 PDF

研究工作台包含三檔選擇、cutoff、授權執行、job狀態、預算、來源和工具軌跡、覆核問題、核准報告與PDF。新報告包括3至5項主張、總經/基本面/估值觀察、DCF假設與限制、反向證據、未知、下一確認訊號及來源。無足夠資料時標不足，不虛構買賣評級或未校準上漲機率。

沿用 report_builder.py 的 fpdf2 與 chart_builder.py 的 matplotlib。研究核准後以同一 report.json 產頁面/PDF，不再呼叫LLM重寫。新增人工核准、report版本與hash鎖定，PDF物件以版本key寫到 Supabase Storage，DB只保存metadata。未核准版本不得由公開端點下載；公開程度由組長依來源授權決定，不把service key放前端。

目前 /output 只是本機檔案路由；Render下 main.py 預設跳過PDF。W07需實作線上產製及保存流程，W08在測試後才設定 ENABLE_PDF_ON_RENDER=1 或等效新worker設定。光開環境變數不等於完成持久儲存。

PDF每份<=5MB、<=10頁，中文字可嵌入、來源可點、關鍵風險不可截斷。100份最壞约500MB另加快照與圖，W01/W08查 Storage/DB 配額、流量、備份和生命週期；到80%停止新增並通知，不自動刪正式資料。Render本機output只作暫存，重啟後仍能讀既有報告才算驗收。

2GB不是API額度。先去重資料抓取、限一次重工作、串行產圖/PDF、量RSS及延遲，再決定資源。chart_builder.py 已有 close(fig)，不得未量測就斷言沒有關圖是慢的原因。總經更新與FinMind資料預取採受控批次及TTL；過期快取明示時間，不冒充即時。

LangGraph官方架構、Gemini工具呼叫、Render規格入口為實作查核入口；版本與實際額度由組長鎖定。
