一句話主軸

沿用現有台股總經、財報、DCF 估值與網頁報告，新增能依證據自主選工具、接受覆核、有限補查與停止的雙 Agent，並在網站呈現可追溯、可下载的同版本 PDF。

組長可直接念的介紹

我們的專題原本就是 Python 投資分析系統：總經部門整理 FRED 與台股市場資料，財報部門取得公司財務資料，估值部門計算 DCF，網站顯示結果與圖表。這些是實際存在的程式基礎，但有程式不等於金融口徑已驗證，也不等於已有自主 Agent。

這學期不換網站框架。Researcher 要能根據缺少的證據決定先查財報、總經或股價；Reviewer 要能獨立檢查來源、財報期間、PE 和 DCF 假設，發現問題就要求補查。若仍然缺資料，系統要明確說不足，不能為了給出買賣評級而編數字。LangGraph 管理狀態與邊界，真正的自主性要用模型選擇工具與不同執行路徑證明。

研究完成後仍需人工核准；網站和 PDF 使用同一份核准資料。公開訪客閱讀既有成果不呼叫模型。執行過程保存工具動作、來源版本、簡短決策理由、呼叫與 token 用量，不展示隱藏思考鏈。最後以固定流程、單 Agent、雙 Agent 的受控比較評估品質與成本，不預設雙 Agent 一定比較好。

組長/A 做執行器及網站，B/C 做資料及研究文稿，D/E 做覆核及成果呈現。C/E 的技術素材由技術組核准後提供，不要求他們寫程式、執行測試或自行判斷財務正確性。

本期固定範圍

  • 示範基線為台股 2330、2317、2454，一次一檔；這是依既有系統訂定的三檔驗收範圍，不表示使用者已逐檔指定或保證資料完整。
  • 固定問題：「截至指定時間，總經、基本面與估值證據支持哪些觀察？有哪些反向證據、假設與待確認訊號？」報告區分事實、推論、未知。
  • 保留 Flask、FinMind、FRED、Supabase、既有 DCF/matplotlib/fpdf2。新增 Python LangGraph 與 Gemini 官方 SDK，不重寫網站。
  • 必做：雙角色自主工具閉環、持久job/來源/軌跡、預算與停止機制、人工核准、季度財報、同業比較、收藏儀表板、網站同版本PDF、三模式研究驗證。小型2D產業圖按第03章條件閘門執行。
  • Render 2GB 是規劃規格，不是已購買；Gemini 以實際免費 API 額度為準，不以學生訂閱推定 API 無限。
  • 不做自動下單、個人化投資建議、獲利保證、全市場擴充、3D 關係網、模型微調、向量資料庫、六 Agent 辯論或任意網址爬取。
  • 既有 DCF 必須保留與核實；不把規則、數學計算器或固定爬資料流程宣稱成自主 Agent。
